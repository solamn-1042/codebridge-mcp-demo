# CodeBridge：基于 DeepSeek Harness 的代码仓库工具插件

**项目时间：** 2026.10—至今

**项目简介：** 面向 Agent 接手陌生仓库与复核代码改动的场景，统一代码检索、按行读取、Git 差异查看和固定检查，提供可追溯的代码上下文与执行结果，并支持在 DeepSeek Harness 中按需启停和重连。

**技术栈：** Python、TypeScript、DeepSeek Harness、Cordis、MCP、SQLite、Git

**项目描述：**

- 基于 Python MCP SDK 实现仓库概览、代码检索、按行读取、Git 差异与固定检查等工具，返回文件路径、行号及具体 patch，帮助 Agent 从改动统计进一步定位实现与修改内容。
- 开发 Cordis 生命周期管理插件，提供状态查询、启停与手动重连；通过 Fiber 挂载和释放官方 DSH MCP Client，启动失败时保留控制入口，支持在同一运行时恢复服务连接。
- 实现仓库相对路径与真实路径检查，拒绝目录跳转和链接访问，排除已知凭证路径；限制代码读取与 diff 输出，检查命令采用白名单、超时终止和结构化异常返回，控制模型的文件访问与命令选择范围。
- 基于 SQLite 记录调用耗时与错误类型，搭建真实 stdio MCP 回归评测；20 轮本地评测中，40 次参数或权限异常后的合法调用全部成功，验证工具异常后的持续调用能力。
