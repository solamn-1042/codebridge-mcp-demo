## 复现

在项目根目录：

```powershell
& '.\.venv\Scripts\python.exe' -m pytest -q --junitxml=.codebridge\python-tests.xml
npm run test:cordis
& '.\.venv\Scripts\python.exe' eval\benchmark.py --rounds 20
```

生成的实际耗时会随机器负载变化。模型任务、Token 消耗与相对 DSH 原生工具的改进幅度，应按 eval/tasks.md 另做对照评测。

## 使用范围

当前验证了独立 MCP SDK 调用与 Cordis/DSH MCP Client 集成，未逐个验证其他 MCP 客户端产品。运行中的旧 DSH 实例需要重新加载更新后的插件与配置；本次没有替换正在运行的 Web 实例。
